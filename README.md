# Les Jardins d'Alex (maquette)

Maquette de site vitrine pour Les Jardins d'Alex, aménagement paysager à Bazemont (78).

Pages : `index.html` (accueil), `prestations.html`, `realisations.html`, `contact.html`, `mentions-legales.html`.

Adresse : https://webaunet.github.io/les-jardins-d-alex/

Les pages sont générées par `outils/build.py` ; les images sont préparées par `outils/optimiser_images.py`.
